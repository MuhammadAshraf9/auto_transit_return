Auto Transit Return on No Backorder

Automatically return remaining quantities from Transit Location

This module enhances Odoo stock operations by automatically creating a return transfer when a user receives less quantity than expected and chooses No Backorder.

Instead of leaving remaining quantities stuck in the Transit Location, the system will automatically generate a return transfer back to the original source location.

Key Features

  • ✔ Automatically handles remaining quantities on No Backorder
  • ✔ Prevents quantities from being stuck in Transit Location
  • ✔ Creates automatic return picking
  • ✔ Return picking is created in Draft state
  • ✔ Fully compatible with Odoo 18 Community

How It Works

  1. Goods are transferred from Source Location to Transit Location
  2. User receives the transfer in the destination location
  3. User receives less quantity than planned
  4. User selects No Backorder
  5. The system automatically creates a return from Transit to Source
